🔐 Quản trị web

Cách lấy chìa khóa GitHub (làm 1 lần mỗi máy/điện thoại):
  1. Mở github.com/settings/personal-access-tokens/new (đăng nhập tài khoản GitHub của web).
  2. Token name: tên tùy ý, ví dụ "admin web". Expiration: chọn 1 năm.
  3. Repository access: chọn Only select repositories → chọn hp-game-shop.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, chép chuỗi github_pat_… dán vào ô trên.
Chìa khóa được khóa bằng mật khẩu và chỉ lưu trong máy này, không gửi đi đâu ngoài GitHub.

Quên mật khẩu? Cài lại trên máy này (cần dán lại chìa khóa GitHub).
